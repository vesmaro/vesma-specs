# Чеклист интегратора — agent-discovery v0

Человеческая проверка соответствия контракту (дополнение к сьюту
`cases.yaml`). Маркеры MUST/SHOULD — по spec.md §3; ссылки AD-nn — для
отчётов конформанса.

## Агент (писатель поля `models`)

- [ ] **AD-01** Поле `models` едет как аддитивный top-level на
      `POST /api/executors/{id}/discovery`; отдельного маршрута/таймера
      нет (§3.1).
- [ ] **AD-02** Чтение конфигов — только по built-in layout-таблице;
      в логе агента нет evidence чтения неназванного поля; scan-эвристик
      нет (§3.3).
- [ ] **AD-03** `auth` выводится только из наличия маркерных полей;
      в payload нет значений `apiKey`/`env_key` ни в какой кодировке
      (§3.5).
- [ ] **AD-04** `base_url` на проводе — `scheme://authority[/base-path]`;
      query/fragment/userinfo отсутствуют во всех отчётах; credential
      query-параметр → host-only или omit (§3.4).
- [ ] **AD-05** Капы: provider ≤ 60; models[] ≤ 50 sorted; installations
      ≤ 64; объект ≤ 16 KiB marshaled; усечение — в `note` строки
      (§3.6).
- [ ] **AD-06** Файл > 8 KiB или unparsable — отсутствие факта, не
      ошибка; в лог не выше info (§3.6).
- [ ] **AD-07** Probe: только loopback, фиксированная таблица портов,
      один GET, timeout 2 с, без credentials; мёртвый порт — quiet zero
      без ретрая (§3.7).
- [ ] **AD-08** Credential-подобная строка в неожиданном поле → строка
      drop до marshal; локальный лог громкий, reason без значения
      (§3.8).
- [ ] **AD-09** Агент не эмитит инцидент-событий — детектор на борде
      (§3.8).
- [ ] **AD-10** Knob `discovery_models: auto|off`; `off` убирает поле
      целиком; неизвестное значение отвергается на старте (§3.9).

## Борда (читатель-ingest)

- [ ] **AD-11** Неизвестный `harness` / `exec_env` → строка drop +
      аудит `discovery.rejected`; словарь не расширился (§3.11).
- [ ] **AD-12** Неизвестные имена `provider` сохранены advisory (§3.11).
- [ ] **AD-13** Credential-подобная строка в неожиданном поле → drop +
      событие `models.credential_leak_suspected` (§3.11).
- [ ] **AD-14** Капы борды: сверх-кап объект → честный `422`, не тихий
      trim (§4).
- [ ] **AD-15** Зеркало — snapshot: последний отчёт выигрывает;
      идентичный повтор — no-op; absent ≠ empty (no-wipe, §3.10).
- [ ] **AD-16** Старый агент (без поля) и борда без зеркала — оба
      состояния конформны; поле принимается-и-игнорируется (§3.1, §7).

## Фикстуры и примеры

- [ ] **AD-17** В `examples/` и документе нет реальных токенов и путей
      машин владельца — только плейсхолдеры и публичные endpoint'ы
      (ADR-0001 §6).
- [ ] **AD-18** Негативные фикстуры используют zero-entropy fake-формы
      (префикс+длина), чтобы триггерить shape-скан, но не gitleaks.
